SDP Signal Panel — Evidence dashboard
=====================================

This directory is git ignored on purpose (see docs/decisions/0017). The tracked
engine is the dbt marts under transform/models/marts/. This is only the view.

Prerequisites
  1. Build the marts first, so the warehouse holds them:
       python -m sdp.transform build --select marts.*
  2. Install Node 18 or later (Evidence is a Node app). For example:
       brew install node

Run
  cd reports
  npm install          # first time only, a large download
  npm run sources      # pull the marts from the warehouse into Evidence
  npm run dev          # serve at http://localhost:3000

The DuckDB warehouse path is set in
  sources/warehouse/connection.options.yaml
Change it if the lake moves.

If npm install fails on a version
  The framework files (package.json, evidence.config.yaml) may be behind the
  current Evidence release. In that case scaffold a fresh template and copy the
  project files in:
     npm create evidence@latest reports-tmp
     cp -r sources pages reports-tmp/
     cd reports-tmp && npm install && npm run sources && npm run dev
  The parts that are specific to this project — sources/ and pages/ — are the
  ones to keep.
